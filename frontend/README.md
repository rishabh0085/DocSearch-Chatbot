# Acme AI Search frontend

React, TypeScript, Vite, Tailwind CSS, Axios, and React Router foundation for the Enterprise Search Platform.

## Development

Copy `.env.example` to `.env` if the backend URL needs to be overridden, then run:

```bash
npm install
npm run dev
```

The development server is available at `http://localhost:5173`. Build a production bundle with `npm run build`.
